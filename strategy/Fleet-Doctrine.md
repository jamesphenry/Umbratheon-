# Fleet Doctrine

**Umbral Dominion Tactical Protocol: FLD-1**  
*"The void does not forget. Neither do we."*

---

## ☗ Overview
The Fleet Doctrine of Strategos Umbratheon is not centered on brute strength—it is built on inevitability. Every ship is a line of code. Every movement a calculated pulse. Victory is not claimed. It is simulated.

This doctrine outlines the foundational fleet composition, response patterns, and unit purpose across Dominion-controlled space.

---

## ⛨ Composition Protocols

### Defense Node Loadout (e.g. Blackthrone)
- **Fighters** (≥500): Point-defense and screen layer
- **Destroyers** (≥5): Standard line enforcement
- **Heavy Cruisers** (≥5): Armor core against skirmish waves
- **Fleet Carriers** (≥4): Mobile command and refit node
- **Frigates/Corvettes**: Tactical scouts, route probers
- **Scout Ships**: Auto-scout enabled for sector vigilance
- **Outpost Ships**: Stationary fallback nodes

*Fleet Size Target: 15,000–30,000 strength for core worlds*

---

## ⬒ Tactical Patterns
- **Decentralized defense**: No static fleets. Fleets patrol or orbit high-value infrastructure
- **Detection layering**: Scout ships auto-enabled, overlapping vision with bases
- **Reactive stacking**: Fleets are layered to absorb first strike, retaliate with heavier wave
- **Fleet hiding**: Units may cloak/hide from guild-level sharing for OPSEC

---

## ⚔ Doctrine Priorities
1. **Defend Throneworlds first.** Blackthrone and Cindervault are non-negotiable.
2. **Fleet mobility over quantity.** Every ship must have purpose.
3. **Interoperability.** Units must support each other. No solo fleets.
4. **Avoid crystal-heavy investments** (unless strategic tech shift occurs).

---

## 🛠 Development Goals
- Introduce **Orbital Shipyards** for dreadnought class capability
- Develop **Jumpgates** for tactical leap deployment
- Integrate **Scout Relay Chains** between outposts
